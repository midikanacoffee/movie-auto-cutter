# ライブ動画 自動曲間認識・分割ツール 実装計画

## 概要
ライブ動画ファイルを入力として受け取り、動画から音声を抽出してGemini APIに送信することで各曲の境界（開始・終了時間）および曲名を自動認識し、ffmpegを用いて曲ごとに自動分割・自動命名して保存するローカルツールを開発します。

---

## セキュリティ・プライバシー保護の最優先方針

> [!IMPORTANT]
> 本プロジェクトでは、APIキーや個人情報、プライベートな映像・音声データを外部やGitリポジトリに漏洩させないための厳格なセキュリティ対策を最優先で実施します。

1. **秘密情報のコミット完全防止**:
   - `.env` などの認証情報ファイルは一切Git管理に含めません。
   - ダミー設定のみを記載した `.env.example` のみを提供します。
   - APIキーは環境変数経由（`python-dotenv` / `os.getenv`）で安全に読み込みます。
2. **メディアファイル・個人情報の保護**:
   - テスト用や実際のライブ動画・音声（`*.mp4`, `*.mov`, `*.mp3`, `*.wav` 等）、および出力ファイル（`output/`）はすべて `.gitignore` で除外します。
3. **プライベートリポジトリ管理**:
   - GitHub上に新規作成するリポジトリは必ず **Private** として作成します。

---

## 採用する対策と設計方針

1. **安全マージンの設定**:
   - AIが認識した曲の開始・終了時刻に対し、前後に数秒のマージン（デフォルト: 開始前2秒、終了後2秒）を付与し、演奏の頭切れを防ぎます。
2. **曲名不明時のフォールバック命名**:
   - 未知の新曲や即興曲の場合でもエラーにせず、「Track_01_歌詞フレーズ」や「Track_01_MC」などの代替名を自動生成します。
3. **軽量化とアップロード制限対策**:
   - 巨大な動画ファイルを直接APIに送るのではなく、ローカルで軽量な音声（AAC/MP3）のみを抽出してGemini APIへ送信します。
4. **キーフレーム問題への対応**:
   - 高速な無劣化切り出し（`-c copy`）をデフォルトとしつつ、秒数ぴったりの高精度カットが可能な再エンコードモードも選べるようにします。
5. **手動微調整の猶予（確認ステップ）**:
   - Geminiが判定したセットリストとタイムスタンプをJSON/テキストとして一旦出力し、分割実行前に確認・編集できる仕組みを用意します。
