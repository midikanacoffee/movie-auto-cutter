# トラブルシューティング & よくある質問 (FAQ)

本ツール利用時によくあるトラブルや疑問、およびその対処法をまとめています。

---

## 1. エラーと対処法

### Q0: エラーが発生したときの詳細ログを確認したい
* **対処法**: プロジェクト内の **`logs/app.log`** に、実行時の詳細な動作ログおよびエラー時のスタックトレースが自動記録されます。
  * エラー原因が分からない場合は、まず `logs/app.log` の末尾をご確認ください。
  * ※ `logs/` フォルダは `.gitignore` によりGit管理外として保護されています。

### Q1: `Gemini APIキーが見つかりません` と表示される
* **原因**: プロジェクト直下の `.env` ファイルが存在しないか、APIキーが未設定です。
* **対処法**:
  1. プロジェクト直下の `.env` ファイルを開きます。
  2. `GEMINI_API_KEY=AIzaSy...` のように、ご自身のGemini APIキーを正しく貼り付けて保存してください。
  3. APIキーは [Google AI Studio](https://aistudio.google.com/app/apikey) から無料ですぐに取得できます。

### Q2: `ffmpeg: コマンドが見つかりません` または `FileNotFoundError`
* **原因**: システムに `ffmpeg` がインストールされていないか、環境変数 `PATH` に通っていません。
* **対処法**:
  * Windowsの場合: [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 等からffmpegをダウンロードし、`bin` フォルダへのパスをシステム環境変数 `PATH` に追加してください。
  * ターミナルで `ffmpeg -version` を実行してバージョンが表示されればセットアップ完了です。

## 2. 仕上がり（分割クオリティ）の微調整テクニック

### Q3: 演奏の頭（最初の1音）が少し切れてしまう
* **対処法**: 開始前の安全マージン（`--margin-start`）を少し広げてください（デフォルトは2.0秒）。
  ```powershell
  # 開始前マージンを3.5秒にして実行
  python main.py "live.mp4" --margin-start 3.5
  ```

### Q4: プレイヤーによって再生開始時に冒頭が一瞬フリーズする、または秒数が1〜2秒ズレる
* **原因**: 高速無劣化カット（ストリームコピー）では、動画内のキーフレーム（Iフレーム）位置に自動吸着してカットされるためです。
* **対処法**: `--reencode` オプションを付けて実行してください。再エンコードにより、指定した秒数通りに1フレーム単位の高精度でカットされます。
  ```powershell
  python main.py "live.mp4" --reencode
  ```

### Q5: 曲名を修正したい、または秒数を手動で微調整したい
* **対処法**: 一旦 `--dry-run` で解析結果のJSONファイルだけを出力し、テキストエディタで修正してから動画分割を実行できます。
  ```powershell
  # 1. まず解析だけ行い、JSONを生成（動画分割はスキップ）
  python main.py "live.mp4" --dry-run

  # 2. 生成された output/live/setlist.json をメモ帳等で開き、曲名や秒数を微調整

  # 3. 編集したJSONを指定して動画分割を実行
  python main.py "live.mp4" --from-json "./output/live/setlist.json"
  ```

### Q6: MC（メンバーのトーク）も動画として保存したい
* **対処法**: ウィザードで `[1] MCも別ファイルとして個別に保存する` を選ぶか、CLIで `--mc-mode separate`（デフォルト）を指定してください。`01_[MC]_トーク内容.mp4` のように別ファイルとして自動切り出しされます。

### Q7: 直前のMCと曲をセットにして1本の動画にまとめたい
* **対処法**: ウィザードで `[2] MCを直後の曲の冒頭に結合して1本の動画にする` を選ぶか、CLIで `--mc-mode attach` を指定してください。
  ```powershell
  python main.py "live.mp4" --mc-mode attach
  ```
  `02_[MC+Song]_曲名.mp4` のように、MCから演奏終了までが1本の動画として切り出されます。

### Q8: 生成された歌詞字幕（.srt）はどうやって使えばいい？
* **対処法**:
  * **PC/スマホでの再生**: 切り出された動画（`.mp4`）と同じフォルダに `.srt` を置いた状態でVLCや一般的なメディアプレーヤーで再生すると、字幕トラックとして自動認識されます。
  * **YouTubeへのアップロード**: YouTube Studioで動画をアップロード後、「字幕」の追加画面でこの `.srt` ファイルを選択すると、自動でタイムコード付き字幕が登録されます。

### Q9: YouTube投稿用情報テキスト（_youtube_info.txt）の使い方
* **対処法**: 動画と同じフォルダに出力される `〇〇_youtube_info.txt` を開くと、AIが生成した「魅力的な動画タイトル」「曲紹介・見どころ入りの概要欄説明文」「おすすめタグ」「歌詞」がまとまっています。YouTube Studioの投稿画面にそのままコピペしてご活用いただけます。

### Q10: オープニングやエンディングの切り出しをオフにしたい
* **対処法**: 
  * ウィザード実行時: 最初の質問で `[4] 保存しない` を選択してください。
  * CLI実行時: `--no-opening` や `--no-ending` フラグを付与してください。
  ```powershell
  python main.py "live.mp4" --no-opening --no-ending -y
  ```

### Q11: 曲名テロップの位置や表示タイミングを変えたい
* **対処法**:
  * **位置**: ウィザードで選択するか、CLIオプション `--overlay-pos` に `bottom_left`（左下）、`bottom_right`（右下）、`top_left`（左上）、`top_right`（右上）のいずれかを指定します。
  * **表示タイミング**: `--overlay-start`（表示開始秒数、デフォルト1.5秒）や `--overlay-duration`（表示維持秒数、デフォルト5.0秒）で調整可能です。
  ```powershell
  # 右上に表示し、開始2秒後から7秒間表示する場合
  python main.py "live.mp4" --fade --title-overlay --overlay-pos top_right --overlay-start 2.0 --overlay-duration 7.0 -y
  ```

### Q12: 歌詞字幕（.srt）が空文字（空白）になっている曲があるのはなぜ？
* **原因**: ライブの音響状況や歓声により、歌詞の聞き取りが困難だったためです。
* **背景**: 無理に推測させるとAIが実在しない歌詞を創作してしまう（ハルシネーション）ため、「はっきりと自信を持って聞き取れた歌詞のみを記述し、不明瞭な場合は空文字にする」安全仕様を採用しています。

### Q13: フェードやテロップなどの演出を指定すると分割に少し時間がかかるのはなぜ？
* **原因**: 演出を画面や音声に焼き込む（合成する）ために、ffmpegが内部で動画の再エンコード（レンダリング）を行っているためです。
* **対処法**: 演出が不要で分割速度を最優先したい場合は、ウィザードで演出を「なし」にするか、CLIで `--fade` や `--title-overlay` を指定せずに実行してください（超高速なストリームコピー方式となり、数秒で完了します）。
