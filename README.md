# Live Movie Auto Cutter (ライブ動画 自動曲間認識・分割ツール)

ライブ動画（MP4等）から音声を抽出し、最新の **Gemini 3.8 Flash** を用いて各楽曲の境界（開始・終了時間）と曲名を自動特定した上で、ffmpegを用いて曲ごとに自動分割・自動命名して保存するローカル完結型ツールです。

---

## 主な特徴

- **対話型セットアップウィザード**: 動画を渡すと、MCの扱いやマージンを [Enter] を押すだけで選べる初心者にも優しい設計。
- **柔軟なMC（トーク）切り出し**:
  - `separate`: MCも曲とは別の独立した動画ファイル（`01_[MC]_内容.mp4`）として個別に切り出し。
  - `attach`: 直前のMCを曲の冒頭に結合し、MCと曲をひと続きの1本の動画（`01_[MC+Song]_曲名.mp4`）として切り出し。
  - `omit`: MCを除外して楽曲演奏のみを切り出し。
- **余裕をもった安全マージン**: 曲頭・曲末の切れを防ぐため、デフォルトで**前後3.5秒**（ウィザードや引数で2.0秒〜5.0秒以上へ自由に変更可能）の余白を自動付与。
- **歌詞字幕 (.srt) の自動生成**: 各曲で聞き取れた歌詞から、動画プレーヤーやYouTubeで利用できる字幕ファイルを自動生成。
- **YouTube投稿用情報 (.txt) の自動出力**: 動画ごとにYouTube用タイトル、概要欄用説明文（曲紹介・見どころ）、雰囲気解説、推定ライブ日時、おすすめタグをJSONおよびテキストファイルとして自動出力。
- **超高速・無劣化カット**: ffmpegのストリームコピー（`-c copy`）により、画質劣化ゼロ・数秒での高速分割を実現。
- **徹底したセキュリティ・プライバシー保護**: APIキー（`.env`）や動画・音声データは `.gitignore` により完全隔離。クラウド側の解析用一時音声も処理完了後に即時削除。

---

## 必要要件

- **OS**: Windows / macOS / Linux
- **Python**: 3.10 以上
- **ffmpeg**: システム環境変数 `PATH` に通っていること
- **Gemini API Key**: [Google AI Studio](https://aistudio.google.com/app/apikey) より無料で取得可能

---

## セットアップ

1. 設定用テンプレート `.env.example` をコピーして `.env` を作成します：
   ```bash
   cp .env.example .env
   ```
2. `.env` ファイルを開き、取得したGemini APIキーを設定してください：
   ```env
   GEMINI_API_KEY=ここにAPIキーを記述
   ```
   > [!NOTE]
   > `.env` ファイルは `.gitignore` により厳重に保護されているため、Gitにコミットされることはありません。

## 使い方

### 方法 1: ドラッグ＆ドロップ（ウィザード対話で安心実行）
動画ファイル（`.mp4`, `.mkv`, `.mov` 等）を、プロジェクトフォルダ内にある **`drag_and_drop_cutter.bat`** にドラッグ＆ドロップしてください。

コンソール画面が開き、以下のウィザードが表示されます（**何も入力せず [Enter] を押すだけで推奨設定が選ばれます**）：
1. **MCの扱い**: `[1] 個別に保存` / `[2] 直後の曲にくっつける` / `[3] 除外`
2. **安全マージン**: `[1] 標準(前後3.5秒)` / `[2] 広め(前後5.0秒)` / `[3] 狭め(前後2.0秒)` / `[4] カスタム`
3. **歌詞字幕＆YouTube情報の出力**: `[1] はい` / `[2] いいえ`
4. **切り出し方式**: `[1] 高速・無劣化カット` / `[2] 高精度再エンコード`

### 方法 2: コマンドライン実行
ターミナル（PowerShell等）から、各種オプションを指定して柔軟に実行できます：

```powershell
# ウィザード形式で実行（対話プロンプトが起動）
python main.py "path/to/live.mp4"

# ウィザードをスキップして即時実行（-y または --yes）
python main.py "path/to/live.mp4" -y

# 直前のMCを曲にくっつけて切り出す場合 (--mc-mode attach)
python main.py "path/to/live.mp4" --mc-mode attach -y

# 前後マージンを広め（5秒）に設定する場合
python main.py "path/to/live.mp4" --margin-start 5.0 --margin-end 5.0 -y

# まずはAIが認識した曲名・タイムスタンプ・YouTube情報（セットリスト）だけ確認したい場合
python main.py "path/to/live.mp4" --dry-run
```

### CLIオプション一覧

| オプション | 型 / デフォルト | 説明 |
| :--- | :--- | :--- |
| `video_path` | 文字列 (必須) | 分割対象のライブ動画ファイルパス |
| `-o`, `--output-dir` | 文字列 (`./output/<動画名>/`) | 分割後動画の保存先フォルダ |
| `--mc-mode` | `separate` / `attach` / `omit` (`separate`) | MCの扱い: 個別保存 / 曲の冒頭に結合 / 除外 |
| `--margin-start` | 数値 (`3.5`) | 曲開始前の安全マージン秒数（頭切れ防止） |
| `--margin-end` | 数値 (`3.5`) | 曲終了後の安全マージン秒数（余韻切れ防止） |
| `-y`, `--yes`, `--no-wizard` | フラグ (`False`) | 対話ウィザードをスキップして即時実行 |
| `--no-subtitles` | フラグ (`False`) | 歌詞字幕 (.srt) ファイルの出力をオフにする |
| `--no-youtube-info` | フラグ (`False`) | YouTube投稿用情報テキスト (.txt) の出力をオフにする |
| `--reencode` | フラグ (`False`) | キーフレーム吸着による秒数のズレを防ぐ高精度再エンコードモード |
| `--dry-run` | フラグ (`False`) | 動画分割を行わず、セットリスト解析とJSON保存のみ実行 |
| `--from-json` | 文字列 (`None`) | 既存のセットリストJSONを読み込んで動画分割のみ実行 |

## 出力先とファイル構成

分割された動画、字幕、YouTube投稿情報、および解析データはすべて **`output/<動画ファイル名>/`** フォルダに出力されます。また、動作履歴は **`logs/app.log`** に自動保存されます。

```text
output/
└── <動画ファイル名>/
    ├── 01_曲名A.mp4                  # 切り出された楽曲動画
    ├── 01_曲名A.srt                  # 歌詞字幕ファイル（プレーヤーやYouTubeで利用可能）
    ├── 01_曲名A_youtube_info.txt     # YouTube投稿用タイトル・概要欄・タグのコピペ用テキスト
    ├── 02_[MC]_トークタイトル.mp4      # （separateモード時）切り出されたMC動画
    ├── 03_[MC+Song]_曲名B.mp4         # （attachモード時）MCと曲が一体化した動画
    └── setlist.json                  # 全曲の詳細メタデータ（曲名・時間・雰囲気・日時・歌詞）

logs/
└── app.log                           # 実行ログおよびエラー時の詳細スタックトレース
```

> [!NOTE]
> `output/` および `logs/` フォルダは `.gitignore` によりGit管理外として隔離されています。

## テスト用サンプル動画の生成

手元にライブ動画がない場合でも、以下のコマンドで15秒の動作確認用サンプル動画（`sample_live.mp4`）を生成できます：

```powershell
python create_sample_live.py
```

生成された `sample_live.mp4` を `drag_and_drop_cutter.bat` にドラッグ＆ドロップして動作をテストできます。
